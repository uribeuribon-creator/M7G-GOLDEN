# M7G ALIEN TRANSITIONS GOD V1 — 150 FX

A separate Windows x64 VST3 product. **Alien Voice remains installed and unchanged.**

* INTRO – ENTRADA / CAMBIO – PUENTE / SALIDA – FINAL: **50 effects each**.
* Four knobs: **CANTIDAD, TIEMPO, MIX, SENSIBILIDAD DE PALABRA**. Simple Spanish tooltips.
* Actual reverse capture/anti-causal reflections, granular pitch/stretch/freeze, cepstral formants, tape/warble, synced stutter/repeat/chops, delay/ping-pong, modulated FDN reverb/shimmer, filtering, chorus/flanger/phaser, distortion/crush, pan/width and modulation.
* Phrase/gap detection and host BPM/PPQ sync. Search, previous/next/random, persistent FAV and session A/B.
* Blue/gold cockpit with actual output waveform: gold intro, cyan bridge, blue clean voice, violet tail.
* Same signed perpetual global **M7G.license**; installer preserves existing authorisation. No per-effect activation or audio upload.

**Important timing:** 2000 ms fixed lookahead, reported to the DAW for playback compensation. INTRO becomes audible before the *delayed* clean phrase. Use for mixing/playback, not zero-latency live monitoring. Allow preroll after starting/seeking. Detection uses 250 ms quiet gaps; bridge needs 300 ms. Finite source fragments and short gaps can limit the transition.

Close Studio One, run **M7G-ALIEN-TRANSITIONS-GOD-V1-Windows-x64.exe**, reopen and rescan VST3. Select a bank and preset, then play the vocal. Use STOP FX to fade a held tail. “Infinite” effects stop at the next phrase/STOP FX/transport stop, with a 30-second safety limit.
