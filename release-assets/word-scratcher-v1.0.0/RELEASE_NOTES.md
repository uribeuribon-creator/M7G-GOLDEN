# WORD SCRATCHER PRO - 300

**300 exact requested presets / 10 categories / Makkine Seven Golden**

Real five-second capture, four-point Lagrange audio reading, forward/reverse
physical platter, inertia/friction/motor/release, crossfader cut/smooth/hamster,
eight editable hot cues, texture/lo-fi/saturation/filtered echo. VINYL pitch follows
speed; DIGITAL uses bundled Rubber Band 3.3.0 time stretch to retain pitch.
Automatic energy/onset/gap capture, learned room-noise floor and intelligent
scratch ducking, with manual platter and preset gestures. Not speech recognition.
Grouped searchable 300-preset selector, animated applied knobs, A/B and favourites.

Windows x64 VST3 installer and complete offline source project with pinned JUCE 7
and Rubber Band code. Native Windows DSP/UI/load/install validation gates precede
publication. Mac AU/VST3 targets exist in source; no validated Mac binary in this release. Existing M7G plugins/licence
preserved. Same public signed ALL/PERPETUAL authorisation file included.

**4224 samples / 88 ms at 48 kHz**, both modes; use DAW delay compensation for
playback/mixing, not zero-latency hardware turntablism. The first scratch starts
after 80 ms of the new word's own captured audio; the full-fragment gesture follows
its detected end/gap. Very slow digital motion fades near stop; ratios are
bounded. Held gestures have a 15-second safety limit. Effects process captured
user audio; no canned word/scratch is in the plugin.

Actual screenshots, measured CPU/callback timings, checksums and clearly labelled
synthetic vowel/speech demonstrations attached. Demos are not human recordings.
Engineering evaluation release: Studio One itself, subjective listening with real
user recordings and laptop-specific CPU targets remain unverified. Unsigned
Windows installer. GPLv3-or-later distribution;
JUCE/Rubber Band commercial licences needed for proprietary closed-source editions.
