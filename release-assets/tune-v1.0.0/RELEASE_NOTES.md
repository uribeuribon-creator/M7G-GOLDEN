# M7G ALIEN TUNE GOD V1 — afinacion, armonias y 100 presets

VST3 Windows x64 independiente. Seis perillas principales, cinco perfiles reales
de afinacion, piano de notas/destinos en directo, forma de onda, cuatro bancos
x25, busqueda, favoritos y A/B. Correccion de centro + efecto robot regulable,
compensacion de formantes, hasta cuatro armonias diatonicas y dos dobles derivados
de la toma. Cada voz generada tiene su propio ancho/color/aire/reverb/drive/pan.
Conserva Alien Voice y Transitions y comparte su licencia perpetua.

YIN/autocorrelacion + CNN ONNX para candidatos; MLP para rasgos acusticos.
Entrenamiento sintetico documentado; no identifica genero/identidad/estilo
musical ni genera nuevos cantantes. Cinco perfiles DSP, no cinco redes vocales.
Los dobles son simulaciones por resintesis, no otras grabaciones reales.

**48 kHz: ESTUDIO 42.67 ms / MONITOR 10.67 ms.** Ademas, la deteccion necesita
periodos/ventanas observados y asentamiento. Sin afinacion de latencia cero.
Monitor cambia detalle por menor latencia; cambia calidad con el DAW detenido.
Seleccion manual de escala disponible; AUTO TONO es una estimacion ambigua.

Cierra Studio One, instala el .exe, reabre y escanea VST3. Elige preset, tonica y
escala; activa armonias/dobles y reproduce voz monofonica. ONNX, modelos y runtime
Visual C++ incluidos, sin Internet durante uso. Una sola licencia global.
