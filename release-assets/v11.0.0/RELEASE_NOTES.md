## Installation / Studio One 7

Close Studio One, run **M7G-ALIEN-VOICE-V11-ALIEN-INTELLIGENCE-Windows-x64.exe**, then rescan VST3 plug-ins. The installer targets `C:\Program Files\Common Files\VST3`. V10 and earlier products coexist; previous sessions retain their original plug-in ID.

Start with **AUTO | ESPECTACULAR** and **AUTO** enabled. Play the recorded vocal. Use **ANALIZAR TODO** for a three-second initial adjustment, or let AUTO adapt continuously. Switch to MANUAL to hold its current values and tweak them. For Vocal Align, feed the principal vocal into the optional **Lead reference** sidechain.
