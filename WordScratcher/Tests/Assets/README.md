# Synthetic speech fixture

`palabra-demo.wav`: original text "Makkine. La palabra manda.", synthesised using
eSpeak NG 1.51 (Spanish voice, speed 145, pitch 42); 22050 Hz mono/16-bit.
Generated solely for DSP tests/demonstration, not a human voice recording.
This audio is not in the production plugin and is never injected into user audio.
