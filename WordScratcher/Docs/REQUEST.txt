Crea un VST3/AU 100% funcional y compilable llamado "WORD SCRATCHER PRO - 300" usando JUCE 7 C++.

REQUISITO NO NEGOCIABLE: El efecto de scratch debe ser REAL, con DSP funcional. Nada de placebo, nada de UI falsa. Debe procesar audio real con time-stretch + pitch + vinilo physics. Si el efecto no scratchea audio real, el plugin es un fracaso.

ARQUITECTURA DSP REAL - CÓMO DEBE FUNCIONAR:

1.  Usa un ring buffer de 5 segundos para el audio de la palabra. El puntero de lectura es controlado por la posición del vinilo virtual (0.0 a 1.0).
2.  Implementa resampling con interpolación Lagrange de 4 puntos para el movimiento. Cuando el usuario mueve el vinilo rápido hacia adelante, lees el buffer rápido hacia adelante. Cuando lo mueve hacia atrás, lees hacia atrás con reverse.
3.  Para evitar cambio de tono tipo chipmunk, integra RubberBand Library (incluye el código fuente de rubberband en el proyecto) para time-stretch independiente. Modo VINYL = pitch sigue velocidad (clásico), Modo DIGITAL = pitch se mantiene.
4.  Añade física real: velocidad del vinilo, inercia (0.85-0.98), fricción, torque del motor. Usa ecuación: velocity = (target_position - current_position) * friction + velocity * inertia.
5.  Crossfader: simple gain gate con curva. Cuando está cerrado, mute. Cuando está abierto, audio pasa.

SISTEMA DE 300 PRESETS PROFESIONALES - DEBEN ESTAR PROGRAMADOS EN CÓDIGO, NO VACÍOS:

Crea una clase PresetManager con un array de 300 structs, cada preset con valores reales que cambian el comportamiento del scratch. Cada preset debe sonar DIFERENTE.

Estructura de cada preset:
struct ScratchPreset {
  String name;
  String category;
  float inertia, friction, motorTorque, releaseTime;
  float pitchRange, vinylNoise, crackle, tension;
  bool vinylMode; // true = pitch sigue velocidad
  int crossfaderCurve; // 0=cut, 1=smooth, 2=hamster
  float hotCuePositions[8];
  float transformerRate;
  float echoDelay, echoFeedback;
  String description;
};
